- **Frontend:** React.js, Vite, JavaScript (ES6+), HTML5, CSS3, Tailwind CSS
- **Backend:** Node.js, Express.js, RESTful APIs, Session/JWT Authentication
- **Database:** MongoDB & Mongoose ODM
- **Version Control:** Git & GitHub

## 🚀 General Setup Guide

To run any project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Khursheed5898/MERN-FullStack_Projects.git
   cd MERN-FullStack_Projects
   ```

2. **Navigate to the specific project folder:**
   ```bash
   cd "(1) My_Portfolio"    # or "(2) DiBot.AI" / "(3) Career_Counselling_Website"
   ```

3. **Install dependencies & start development server:**
   ```bash
   npm install
   npm run dev
   ```
